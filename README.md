🚚 ERP Alimentos Pro - Sistema Web de Gestão Interna

Sistema Web de Gestão Interna (ERP) desenvolvido sob medida para distribuidoras de alimentos. O projeto foi estruturado para modernizar a operação, centralizar o controle de estoque, acompanhar vendas e automatizar a gestão financeira e o DRE.

🔗 Demonstração ao Vivo: https://af023.github.io/Sistema-gestao-distribuidora/

🚀 Tecnologias Utilizadas

Front-end: React.js / HTML5 + Tailwind CSS (Interface Moderna e Responsiva)

Back-end: Node.js (API RESTful)

Banco de Dados: PostgreSQL (Hospedagem em nuvem via Supabase)

Gráficos & Dashboards: Chart.js

Hospedagem: GitHub Pages (Demonstração) / Vercel + Supabase (Database & Auth)

📌 Principais Funcionalidades

📊 1. Dashboard Gerencial em Tempo Real

Visão geral de faturamento mensal, ticket médio e volume de pedidos.

Gráficos de Fluxo de Caixa acumulado e projeção financeira.

Ranking visual dos 4 produtos mais vendidos.

📦 2. Controle de Estoque com Alerta Automático

Tabela completa de produtos com indicativo de nível crítico de estoque.

Alertas de reposição urgente quando a quantidade atinge o limite mínimo.

Filtros dinâmicos e busca rápida por SKU ou nome do produto.

Modal para cadastro e edição de novos produtos.

🛒 3. Gestão de Vendas & Pedidos

Acompanhamento do status de pedidos (Faturado, Em Separação, Entregue).

Histórico completo de vendas organizadas por cliente e data.

💰 4. Financeiro & DRE Sintético Automático

Demonstrativo do Resultado do Exercício (DRE) calculated automaticamente.

Margem de lucro bruto, abatimento de impostos e custo de produtos (CPV).

Painel de Contas a Pagar e Contas a Receber dos próximos 7 dias.

👥 5. Cadastro Unificado de Parceiros

Cadastro centralizado de Clientes VIP e Fornecedores Diretos.

Controle de CNPJ, endereço e contatos comerciais.

📁 6. Importador de Planilhas Excel

Módulo de migração simples para upload de arquivos .xlsx / .csv.

Validação automática de dados antes da gravação no banco PostgreSQL.

🔐 Controle de Permissões (RBAC)

O sistema conta com controle de acesso por perfil de usuário:

Administrador: Acesso total a relatórios, DRE e configurações.

Gerente de Estoque: Gestão de produtos, entradas e saídas.

Vendedor: Emissão e acompanhamento de pedidos de vendas.

Financeiro: Controle de contas a pagar/receber e relatórios fiscais.
